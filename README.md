
# MarketPulse

MarketPulse is a full-stack financial market data analytics
platform built with Python, FastAPI, React, TypeScript,
and PostgreSQL.

## Project Goals

- Ingest historical and real-time financial market data
- Build reliable data processing pipelines
- Develop interactive financial analytics dashboards
- Explore database optimization and system performance
- Apply production-quality software engineering practices

## Tech Stack

- Backend: Python, FastAPI
- Frontend: React, TypeScript, Vite
- Database: PostgreSQL
- Market Data: Alpaca API
- Infrastructure: Docker, GitHub Actions

## Status

Under active development.
